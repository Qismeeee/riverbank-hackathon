# Riverbank Hackathon

Riverbank thẩm định vốn lưu động theo dòng tiền payout của seller Shopee. Code tính số, model diễn giải, nhân sự ngân hàng quyết định.

Bắt đầu từ [Agents/README.md](Agents/README.md), đọc [AGENTS.md](AGENTS.md) và chọn công việc trong [NEXT_STEPS](Agents/NEXT_STEPS.md).

- `Agents/`: BRD, SRS, SAD, nghiệp vụ, API, dữ liệu, nghiệm thu và hướng dẫn Codex.
- `policy/`: tham số quy phạm, ý nghĩa rule và fixture tính tay.
- `knowledge/`: prompt, thuật ngữ và guardrail.

Đây là bộ tài liệu khởi tạo dự án, đã đồng bộ contract mới nhất từ repo Riverbank nguồn và chuyển thành doc-first. Backend, source frontend, Makefile và test được xây theo kế hoạch triển khai; build artifact không được coi là source. Các đường dẫn code trong đặc tả xác định cấu trúc cần xây, không phải tuyên bố chức năng đã hoàn thành.
